# Scanalyzer · 08 · VISUALIZERS

This folder contains the visualizer display widgets and multi-dimensional graphing components of the **Scanalyzer** system.

## Modules

| Module Name | Repository / Path | Description |
| :--- | :--- | :--- |
| **`VISUALIZER.2D-Graphs`** | `LikeDotAudio/APK.softapp.SCANALIZER.Visualizer.2D-Graphs` | 2D line plot, spectrum analyzer, and time-series waveform graph renderer. |
| **`VISUALIZER.3D-PointCloud`** | `LikeDotAudio/APK.softapp.SCANALIZER.Visualizer.3D-PointCloud` | 3D WebGL point cloud renderer for multi-dimensional feature space visualization. |
| **`VISUALIZER.4D-FaceBall`** | `LikeDotAudio/APK.softapp.SCANALIZER.Visualizer.4D-FaceBall` | 4D spherical projection and faceball vector visualizer. |
| **`VISUALIZER.5D-MultiVector`** | `LikeDotAudio/APK.softapp.SCANALIZER.Visualizer.5D-MultiVector` | 5D multi-vector tensor and high-dimensional audio descriptor visualizer. |
| **`VISUALIZER.Examiner`** | `LikeDotAudio/APK.softapp.SCANALIZER.Visualizer.Examiner` | Deep item examination widget showing raw binary structure, tags, and sidecar inspection. |
| **`VISUALIZER.Simple-Data-Graphing`** | `LikeDotAudio/APK.softapp.SCANALIZER.Visualizer.Simple-Data-Graphing` | Lightweight bar chart and data graphing faceplate component. |
